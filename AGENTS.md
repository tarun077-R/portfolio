# Repository Rules & Philosophy

## Ponytail: The Ladder of Simplicity
Before implementing any feature or modification, climb the Ponytail Ladder:
1. **YAGNI**: Don't write code for hypothetical futures. Delete dead code and unreferenced assets.
2. **Reuse**: Check existing components, CSS variables, and data structures first.
3. **Native Platform First**: Prefer native CSS, HTML5 semantic tags, and browser APIs over custom JavaScript abstractions.
4. **Zero Heavy Runtime Libraries**: No Tailwind, Framer Motion, GSAP, or Three.js. Pure React + CSS Custom Properties + WebGL.
5. **Preserve Hard Boundaries**: Never sacrifice WCAG AA accessibility, keyboard navigation, or core design fidelity.
